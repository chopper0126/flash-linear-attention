# 知识点

## elu(x)+1（非负激活）

线性注意力 / GDN / DeltaFormer 中常用的非负激活函数，把任意输入 x 映射到恒正区间。

### 公式分段（默认 α=1）

- x > 0 时：elu(x) = x → **elu(x)+1 = x+1**
- x ≤ 0 时：elu(x) = eˣ−1 → **elu(x)+1 = eˣ**

### 数值例子

| x | elu(x) | elu(x)+1 |
|---|--------|----------|
| 2.0 | 2.0000 | **3.0000** |
| 1.0 | 1.0000 | **2.0000** |
| 0.0 | 0.0000 | **1.0000** |
| −0.5 | e^−0.5−1 ≈ −0.3935 | **0.6065** |
| −1.0 | e^−1−1 ≈ −0.6321 | **0.3679** |
| −3.0 | e^−3−1 ≈ −0.9502 | **0.0498** |

### 关键性质

- 输出恒 > 0：负输入被映射到 (0, 1)，正输入线性增长——保证 kernel 非负；
- 负半轴恰等于 eˣ，正半轴线性增长，不像 exp 那样指数爆炸，数值稳定；
- 实现技巧：`elu(x) + 1 = torch.where(x > 0, x + 1, exp(x))`。

### 相关位置

- 出现在 GDN / DeltaFormer 的 `f = elu(x) + 1` 状态递推（chunk 递推）及其梯度推导中。
